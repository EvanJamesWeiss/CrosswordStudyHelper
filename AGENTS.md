# Project Agents

The agents working on this application are experts in the following areas:
- Google Chrome Extensions
- JavaScript (ES6+)
- HTML5 & CSS3
- Web Programming Languages and Paradigms

## Quality Standards

To ensure the reliability and maintainability of the CrosswordStudyHelper extension, the following rules must be strictly followed:

1. **Test-Driven Development**: All changes and new features must be protected by corresponding test cases.
2. **Code Coverage**: The project must maintain **100% code coverage** at all times.
3. **Continuous Verification**: After every change, the test suite must be executed to verify that all tests pass and coverage requirements are met.
4. **Docker Integration**: Agents should default to using Docker whenever interacting with the application (e.g., for builds, testing, or environment management). **Note: `npm test` should NEVER be run locally; always run it within the Docker container.**
